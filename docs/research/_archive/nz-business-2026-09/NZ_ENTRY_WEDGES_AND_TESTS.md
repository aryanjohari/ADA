## 3. One-liner

A cited, model-agnostic **scorecard sheet** of New Zealand entry wedges — format, product, media, connect, hybrid; invent-or-adapt first-class — with **qualitative scores**, a **hard cap on live tests**, and named falsifiers, so a solo operator can prove demand and learning **before** heavy software without locking a niche or cloning a unicorn.

## 4. Core research question (wedges/tests-level)

Which **entry wedges** (named mix of Step 4 archetypes + a lightweight loop) are **test-worthy now** for a solo NZ digital operator — such that demand capture, owned audience, fulfillment, and a learning-loop metric can be proved under **institutions + PSW = OPEN/verify** — and which should stay **scorecard-only** or **research-only**, given substitute pressure and NZ scale, until evidence (or a named graduation rule) overturns that disposition?

## 6. Scorecard method (columns from Step 4 §10; weights as INTENT; no fake precision)

*Step 4 specified **what to score**. This section specifies **how**. Dispositions are **INTENT + HYPOTHESIS**, not market-winner EVIDENCE.*

### 6.1 Columns (every wedge)

| Column | What is scored |
|--------|----------------|
| **Wedge ID / name** | Survey handle. Not a brand. |
| **Archetype ID(s)** | Step 4 mix (e.g. A-F-1 + A-M-1). |
| **Horizon** | **Now** (on-ramp) / **Later** (if Now shows demand/learning). Live tests = Now only. |
| **Loop weight** | Light / medium / heavy (Step 4 §6.3). Prefer light until evidence. |
| **Latent-class originality** | Named mechanic + named audience + named distribution twist. Fail if “category + ads” only. |
| **Demand-capture path** | Search / ads / advisor / place social → owned. Note IAB rent; **do not invent CPC**. |
| **Owned-audience path** | Consent mechanism; UEM + Privacy feasible? Harvested lists = **fail**. |
| **Fulfillment** | Kit / serial / intro / licensed third party. Who completes the job? |
| **Learning-loop metric** | What a **capped** test would show (GSC / ads / signup / refund). No pipeline implementation here. |
| **Substitute pressure** | Named Step 3 players **and** behaviours (Groups, accountant, DIY). |
| **Institutions thickness** | Baseline vs FAP / REA / trades / therapeutic. |
| **PSW / hiring / licence** | Always **OPEN / verify**. Flag employee need. Never auto-green. |
| **Geography** | Auckland-dense vs corridor vs national. Do not exclude corridors a priori (F-NZ-1-5). |
| **FTA honesty / anti-doorway** | Pass / fail design lock. Rank-and-rent row must run this test. |
| **G8 / pipeline temptation** | If A-H-2-shaped, tag **candidate-not-thesis**. |
| **Graduation rule** | What evidence would justify software / richer pipeline (**Later**). |
| **Structure friction (A-H-5)** | Solo vs citizen-partner — **OPEN / verify**; not a wedge name. |
| **Scorecard vs live** | Disposition under the cap in §9. |

### 6.2 Bands (INTENT — not a 7.3/10)

Numeric scores would fake precision (charter: no invented TAM/CPC). Use **bands**:

| Band | Meaning |
|------|---------|
| **Strong** | Compatible with spine + distinctive mechanic; substitutes do not obviously kill a *capped* test |
| **Mixed** | Plausible but crowded, network-thin, or easy to fake originality |
| **Weak** | Likely loses to a named substitute or thick-licence trap within a short test window |
| **Fail** | Violates design lock (doorway, harvest, unicorn mandate, TV plan, G8-as-thesis, counsel-as-green) |
| **UNKNOWN** | Not established; do not fill with invented CPC/TAM |

**Disposition bands (INTENT):**

| Disposition | Meaning |
|-------------|---------|
| **Live-eligible** | May occupy the **one** concurrent live slot (§9). Not a lock. At most one of these is live at a time. |
| **Scorecard-watch** | Keep on the sheet; may replace the live slot if the occupant is killed or graduates |
| **Scorecard-only** | Stay on paper this cycle (network, licence, or originality too thin to spend the live cap) |
| **Research-only** | Compared for honesty; default **not live** unless named evidence overturns (Later-heavy, anti-card, doorway-fail) |

### 6.3 Weights (INTENT, qualitative — not a formula)

If a reader needs a tie-break, apply in this **order** (not additive points):

1. **Fail filters first:** FTA/anti-doorway, UEM harvest, unicorn/TV/G8-as-thesis, PSW hiring-heavy until cleared, thick personal licence.
2. **Horizon:** Later cannot take the live slot.
3. **Loop weight:** Light > medium > heavy for *this* cycle.
4. **Latent originality:** Invented ritual/audience/distribution > localisation-only clone.
5. **Learning measurability:** Can a capped test produce GSC/signup/refund signal without a platform?
6. **Substitute honesty:** Named incumbents/behaviours, not “the market is empty.”
7. **G8 tag:** A-H-2 may score Mixed; it **cannot** win the live slot *as thesis*.

**Do not** average these into a single number.

### 6.4 Scoring biases carried from Step 4 §10.2–10.4

1. Plural families on the same sheet — reader must not conclude “NZ marketplace.”
2. Invent variants are first-class (Receipt, Corridor, Seasonal kit, Advisor artefact, Shortlist theatre, Format-as-product).
3. Anti-card **A-C-X** appears **to be compared**; default **research-only** unless evidence overturns incumbents + institutions + PSW.
4. G8 is a **column**, not the title.
5. At ~5.3M people and incumbent classifieds/jobs/tradie/news/accounting, **lightweight owned loops** are the more plausible *test* shape (**HYPOTHESIS**) — not assumed winners.
6. Cash track stays separate (charter): day-job survival ≠ asset-thesis success.
7. Rank-and-rent / programmatic local pages + lead capture is a **real** hybrid shape: scorecard-ok **only** if pages are genuinely useful; thin doorway/rent farms = **fail / research-only**. Not the program lock.
8. **A-P-5** is exactly one Later/heavy row so the vertical-efficiency family is not forgotten. Unnamed industry. Default research-only. Do not title a school product. Do not start by making the app.

## 11. Measurement notes (GSC/ads/signup as future learning; no pipeline implementation)

*Research informs **what to look at** if/when a Now occupant exists. This card does **not** implement Search Console, Ads, ISR, CMS, or email infrastructure.*

### 11.1 Search (GSC) — if a property is later verified

**EVIDENCE (product docs, not NZ demand):** Google Search Console Performance reports show **impressions** (how often a link to the site was seen on Google Search / News / Discover), **clicks**, **CTR** (clicks ÷ impressions), and **average position** (Search). Data can be grouped by query, page, country, device. ([Google Search Console Help — impressions, position, clicks](https://support.google.com/webmasters/answer/7042828); [Performance report overview](https://support.google.com/webmasters/answer/7576553). **Do not:** scrape Search Console at scale; treat GSC as a TAM; implement ISR here.

### 11.2 Ads — optional paid proof, not a moat

**EVIDENCE:** IAB NZ CY 2025 Search advertiser revenue **$1.44b** (industry **Tier B**) — rented attention is real. Vertical CPC = **UNKNOWN** at Tier A. ([IAB NZ Q4 CY 2025](https://www.iab.org.nz/news-resources/q4-cy-2025-iab-new-zealand-digital-advertising-revenue-report). Accessed 2026-09-13.)

**FTA overlay:** Ads are “in trade”; unsubstantiated representations are prohibited even if later true; overall impression matters. ([Consumer Protection — FTA](https://www.consumerprotection.govt.nz/general-help/consumer-laws/fair-trading-act); [ComCom — Making accurate claims](https://www.comcom.govt.nz/business/dealing-with-typical-situations/making-accurate-claims/). Accessed 2026-09-11 / 2026-09-13.)

### 11.3 Signup / owned audience

**EVIDENCE:** UEM Act 2007: commercial electronic messages with a NZ link need **consent**, accurate **sender identity**, **functional unsubscribe**; **no address-harvesting software / harvested lists** for unsolicited commercial messages. ([DIA — Commercial electronic messaging](https://www.dia.govt.nz/Spam---Commercial-electronic-messaging-in-New-Zealand); [legislation.govt.nz — UEM Act](https://www.legislation.govt.nz/act/public/2007/0007/latest/dlm405134.html).
