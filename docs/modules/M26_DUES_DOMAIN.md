## Signal / organism purpose (reference know, cited)

Humans are signal-driven organisms. Dues capture exists so ADA can later read **which loops are still open** and **remind without spam** — not so the cortex can role-play a project manager, a GTD coach, or a kanban board.

Dues are the same **job** as food lines, gym sets, time blocks, and habit ticks: one honest grain per named thing. Different **physics**: not grams, not kg×reps, not duration, not a `local_day` tick. A due is an **open loop** (`status=open`) until unique done. Optional `due_at` / `remind_at` are stamps on that loop — not a calendar product.

| Why log | What the signal is **for** |
|---------|----------------------------|
| Loop `id` + title | Which open loop — operator surface; code binds id |
| `due_at` (optional) | When it is due. Today strip `due_todos` when `due_at <= now` |
| `remind_at` (optional) | When to ping. Today strip `remind_soon` in the next 24h. **Not** `next_wake_at` (campaign-only; fail closed on todos) |
| Unique done | That loop closed. Confirm **none**. 0 or >1 title matches → **miss**, do not guess |
| Honest list | `due_list` = open `kind=todo` rows. Reflection is this list + Today strip — not a week SQL organ |
| Session vs other organs | Due chip ≠ habit tick ≠ time block ≠ meal ≠ lift. Bare `thesis` ≠ a due |

**Interpretive classes only — no invented todos.** A todo row comes from `memory_open_loops_upsert` via `due_spine` (add/remind/done). This card does not assign “thesis = Friday 17:00.” Today dues/reminds are YAML/rules on existing loops — not a mouth-invented inbox.

**Personal informatics:** collection (this organ) is the daily path; integration/reflection (`due_list`, Today strip, later briefs) wait until loops are honest ([Li et al., CHI 2010](https://doi.org/10.1145/1753326.1753611); [Choe et al., CHI 2014](https://doi.org/10.1145/2556284.2556964)). Live spine is the required write. Campaigns / project trees / ntfy product / calendar sync are **PARK**, not a 7-pass blocker, not a second organ.
