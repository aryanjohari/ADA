## Signal / organism purpose (reference know, cited)

Humans are signal-driven organisms. Habits capture exists so ADA can later read **whether named repeats happened** — compounding across days — not so the cortex can role-play a coach, a shame streak, or a Tiny Habits textbook.

Habits are the same **job** as food lines, gym sets, and time blocks: one honest row per named bout. Different **physics**: not grams, not kg×reps, **not duration**. A tick is happened-or-not on a `local_day`. Shower/skincare **clock** stays **one** time block (`time_start`); habits may tick `skincare` as a checklist item — **do not** split the clock into per-step timers.

| Why log | What the signal is **for** |
|---------|----------------------------|
| Named habit (`habit_id` + display name) | Which repeat — operator surface; code binds id |
| Tick (`kind=done`) | It happened this `local_day`. Unique one done-row per habit per day |
| Miss (`kind=miss`) | Honest “did not” — first-class row. **No** fake streak. **No** guilt essay |
| Honest absence | Laundry every 2–3 days ⇒ some days with **no** tick = no row, not a calendar fill |
| Empty list | Teach-in Confirm-create (already in `habit_spine`) — **not** silent invent |
| Session vs other organs | Skincare **checklist** ≠ shower/skincare **clock**; gym **sets** ≠ habit tick; breakfast **foods** ≠ habit tick |

**Interpretive classes only — no invented ticks.** A `done`/`miss` row comes from `life_habit_do` / `life_habit_miss` (or Confirm-create + `tick_after`). This card does not assign “skincare = N-day streak.” Continuity **rate** is SQL on existing events — not a mouth-invented streak.

**Personal informatics:** collection (this organ) is the daily path; integration/reflection (day/week SQL, P4 charts) wait until logs are honest ([Li et al., CHI 2010](https://doi.org/10.1145/1753326.1753611); [Choe et al., CHI 2014](https://doi.org/10.1145/2556284.2556964)). Live spine is the required write. `routine_run` multi-step checklist **product** is **OPEN later**, not a 7-pass blocker, not a second organ.
