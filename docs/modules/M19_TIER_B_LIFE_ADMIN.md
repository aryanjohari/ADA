# PASS 1 — Market / fiction / SOTA (no operator prefs)

## P1.1 Human life-admin ontology (jobs-to-be-done)

Adults “admin” their lives across recurring surfaces. Market products cluster here even when branding says “AI assistant.”

| Domain | Typical jobs | Sticky loop (market pattern) | Failure mode if hollow |
|--------|--------------|------------------------------|------------------------|
| **Time** | What’s next; focus blocks; chores vs deep work; don’t miss appointments | Morning brief + due surface + interrupts | Calendar clone; notify spam |
| **Body / training** | Log lifts; follow split; see PRs / coverage gaps | Session log → progress charts | Freestyle “coach” with no log |
| **Food / nutrition** | Log meals; hit macros/micros; trend vs goal | Say/scan → nutrient totals | Photo AI without provenance |
| **Money / receipts** | Capture spend; renewals; reimbursements | Inbox/photo → structured receipt | Silent autopay |
| **People / kin** | Birthdays; who-is-who; keep-in-touch | Contact card + remind | CRM spam; wrong identity |
| **Work / career** | Pipeline; tailor CV; follow-ups | Tracker board + draft pack | Auto-apply spam / ToS |
| **Home lite** | Chores, renewals, packages | Due + checklist | HA theater as substitute |
| **Health habits** | Skincare, meds, streaks, miss-days | Tiny daily capture | Shame streaks |
| **Travel** | Pack lists; docs; timers | Checklist + notify | Wallet auto-buy |
| **Documents** | Store, find, version admin PDFs | Artifact shelf + cite | RAG-brain without files |

### JTBD table (compact)

| # | Job statement | Success look | Confirm posture (market norm) |
|---|---------------|--------------|-------------------------------|
| J1 | Capture once → structured forever | Object on a board/log, not chat prose | Low for capture; high for overwrite |
| J2 | Don’t forget dues / birthdays | Honest wake within quiet hours | Soft notify |
| J3 | Log body/food with near-zero friction | Same-day streak continuity | None for log append |
| J4 | See progress vs goal | Weekly digest with numbers | Read-mostly |

| J8 | Admin shelf: projects + facts + open loops | One glance Today | Accept plan for multi-step |

**EVIDENCE:** calorie trackers, gym loggers, mail triage agents, personal CRMs, and job trackers each own **one sticky capture surface** — not a general chat that “remembers vibes.”

  - surface: "Dad"                       # what operator might say

  birthday: { days_before: [7, 1, 0] }

### Resolution algorithm (pack: `who_is` / any person-bearing verb)

```text
mention → normalize
  → exact alias match (operator-scoped)
  → dialect term + kin side disambiguation
  → display_name fuzzy
  → if 0: ask to create
  → if 1 high-confidence: bind
  → if many / clash: Confirm sheet with candidates (never silent pick)
```

### Failure modes

| Failure | Mitigation |

| Notify wrong birthday person | Resolve must cite person_id on due |

**Tag:** dialect tables = **FEASIBLE**; cultural completeness = ongoing operator data, not model omniscience (**POLICY** refuse mind-read).
