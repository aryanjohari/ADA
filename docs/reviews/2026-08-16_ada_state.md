## Executive verdict

1. ADA today is a **permissioned ReAct organism on a Pi**, not a chatbot and not an embodied OS — M14–M16 metal is real; **daily habit is not armed**.  
2. The gap is no longer “build organs.” It is **fill + arm + use**: dues/reminds empty, artifacts empty, `ntfy.env` absent, systemd timers **not installed**, personal FACTS thin.  
3. Differentiation already exists (body receipts, gateway+Confirm, allowlist cites, Tailscale, dual-store, Dream manage). Most of it is **under-leveraged** vs lab smoke campaigns.  
4. **North-star vertical (next 30 days):** *Personal ops — track / brief / notify* riding M15+M16.  
5. **Backup vertical:** *Cite-shelf research buddy* (arxiv/pack allowlist + M09 watches → artifacts).  
6. Do **not** center product on M06 smoke campaigns, Funnel, Mem0/Letta/n8n/HA transplants, or long-horizon theater.  
7. Next 2–4 weeks = **adoption sprint** on shipped Phase 0/1, not a new module factory.  
8. Success is measurable: open→act on dues/artifacts, notify/brief receipts, ≥1 real cite→doc/week — not “sounds like Jarvis.”  
9. Lab framing stays: harder-correct geometry; PhD-prep is a **consumer** of the cite/watch path, not a second product.  
10. Operator can pick vertical + backlog below without another strategy debate.

ADA is a **Tailscale-remote agent home** over a Gemini cortex: chat owns the viewport; Body drawer holds organism truth; Plan Accept and Confirm bind to gateway `{tool,args}`; durable objects live on `/mnt/ada-data` (FACTS, open_loops, cites, artifacts, runs, Dream). Constitution framing is **personal lab + daily companion + PhD-prep learning surface — not a ship product**. Live posture: HUD process up; birth syllabus present; prefs = defaults + rich web allowlist; **8 open_loops** (3 lab-shaped campaigns + 5 undated todos); **0 artifacts**; **3 cites**; **notify off / no ntfy secret**; **ada-brief / ada-dream timers not enabled**.
